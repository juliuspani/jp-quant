  [tendencia-donchian-1.0.0-rejilla.json](specs/tendencia-donchian-1.0.0-rejilla.json), con el mismo hash de datos

  El error se cierra en el registro como `fallido`, y cuenta en N, como exige el protocolo (`quant-research` §1 y §10).
- No se volvió a ejecutar nada sobre datos reales para buscar la causa: se buscó con datos sintéticos, que no cuentan como
  prueba.

## Causa y arreglo

[ADR 0033](../../adr/0033-polvo-y-stops-cruzados.md). Con liquidez fina, el venue simulado llena las órdenes en parte, y
pueden quedar restos por debajo del mínimo del mercado (polvo). El motor borraba el stop de ese resto; si el precio subía y
el resto volvía a ser vendible, la posición reaparecía sin stop y el motor lanzaba. Un escenario sintético reproduce el
error exacto con el código de este experimento. Además, un stop que el precio ya había cruzado se reintentaba sin fin,
con miles de eventos por vela.

El arreglo conserva el stop del polvo, convierte un stop que no se puede colocar en una salida urgente a mercado
(`trading-risk` §2.4) y no repite un stop rechazado hasta la vela siguiente. Dos pruebas de sistema fallan con el código de
este experimento y pasan con el arreglo.
